# 历史回溯研究档案

这里用于保存历史回溯、研究重建或事后分析。此类材料不具有事前时间戳证明，不能与 `commitments/` 和 `reveals/` 中的前瞻记录混为同一类证据。

任何新增材料都必须明确样本范围、生成日期、数据版本、假设与局限，不得只选择表现较好的阶段。

公开仓库只保存 `evaluation/public/history.json` 中的聚合指标和快照哈希，不保存可还原每日状态的历史原始表。

## 2026-10-20 漏发恢复

用户要求补齐 2026-09-30 之后漏发的信号。`retrospective-request.json` 登记实际补录时间和 10 月 8、9、12、13、14、15、16、19 日；这一整段缺口不按信号好坏筛选。数据读取当时数据库中保留的观测值，不具备过去日期的事前公开证明，也不能证明数据库过去从未改写。

`evaluation/public/retrospective-signals.json` 是近期窗口内的例外补录视图：仍需满足五个后续交易观测日才能公开状态，超出最近 20 个 commitment 日期覆盖的窗口后移除逐日状态，只保留历史聚合。补录单独展示，不进入 commitment 链、已验证条数或事前绩效。原有承诺、哈希和失效修订继续保留。
