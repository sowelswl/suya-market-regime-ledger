FIVE MARKET STATES

只记录市场状态，
不替任何人决定仓位。

  1. -2强空近空仓／可轻微空头
  2. -1弱空降低多头暴露
  3. 0看平轻微多头
  4. +1弱多适度多头
  5. +2强多较高多头

这套时序信号是组合风险暴露的高价值上游输入，也是一项持续迭代的核心研究资产。它采用右偏的多头风险暴露梯度：空档主要用于降低风险，只有强空才允许极轻微空头。具体仓位仍需按个人风险偏好映射。

HOW VERIFICATION WORKS

哈希负责锁定内容，
外部时间证明负责锁定时间。

仅有 Git 历史不够。每个承诺文件还会由独立透明日志记录存在时间，避免通过改写仓库历史伪造更早的发布日期。

  1. 01

    生成

    20:00 左右从只读数据库连接读取策略 3.2 的最新五档 prediction，并检查日期与策略标识一致性。

  2. 02

    承诺

    状态与 256 位随机 nonce 经过 RFC 8785 标准化，再计算 SHA-256；公开文件不包含状态。

  3. 03

    见证

    公开文件由 Sigstore / Rekor 透明日志见证。GitHub 仓库只是原始证据入口，不是阅读门槛。

  4. 04

    揭示

    五个后续交易观测日后公开状态与 nonce，并附上被预测的下一交易日五个宽基实际涨跌；事前证明与事后结果分开核对。

INDEPENDENT VERIFICATION

验证在你的浏览器里完成。
