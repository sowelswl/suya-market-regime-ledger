HOW VERIFICATION WORKS

哈希负责锁定内容，
外部时间证明负责锁定时间。

仅有 Git 历史不够。每个承诺文件还会由独立透明日志记录存在时间，避免通过改写仓库历史伪造更早的发布日期。

  1. 01

    生成

    20:00 左右从只读数据库连接读取最新 `trend5mcx` 五档信号，并检查日期与字段一致性。

  2. 02

    承诺

    状态与 256 位随机 nonce 经过 RFC 8785 标准化，再计算 SHA-256；公开文件不包含状态。

  3. 03

    见证

    公开文件由 Sigstore / Rekor 透明日志见证。GitHub 仓库只是原始证据入口，不是阅读门槛。

  4. 04

    揭示

    五个后续交易观测日后公开状态与 nonce，任何人都可以重新计算并核对原承诺。
